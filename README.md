# CLI Notes App

A command-line Notes application built using Node.js.

## Features

- Add notes
- View notes
- Update notes
- Delete notes
- Store notes in a JSON file
- Command-line interface
- Persistent local data storage

## Technologies Used

- Node.js
- JavaScript
- File System (fs)
- Readline
- JSON
